## mlv-app/every-named-successor-becomes-a-card
rule: every follow-up a lane names, in its summary or in any section of a report it writes, becomes a card. A conditional one ("if X holds, try Y") is filed as a held card that carries its trigger, never left as prose. A named follow-up that no card or reconciler row picks up raises a stuck-row alarm naming the file and line. A harvester that reads only a summary's first line does not meet this rule. It applies to every board whose lanes write free-text summaries or reports.
mechanism: the board's automatic successor filing read only line 1 of a bench lane's summary. A frame-trace report named two successors in its own section. The hub queued the first by hand; the second, conditional one (parallel reconstruction workers, the lever for a CPU path at 40.5 ms of a 41.7 ms frame budget) was never filed. It surfaced only when the owner asked why multiple workers had never been tried.
check: none yet. The board's card SUCCESSOR-SECTION-HARVEST-1 is queued; its RED test is that frame-trace report, which the line-1 harvester misses.
